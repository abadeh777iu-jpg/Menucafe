# لایسنس مدیران رستوران

این یادداشت خلاصهٔ روند کار فروش و ورود مدیران است. جزئیات گام‌به‌گام در `cloudflare/README.md` بخش‌های ۳ب و ۴ آمده است.

## روند
1. فروشنده با `make-superadmin.mjs` یک حساب فروشنده می‌سازد و با آن در `/super` وارد می‌شود.
2. فروشنده در `/super` رستوران را ثبت می‌کند.
3. فروشنده برای آن رستوران یک **کلید لایسنس** می‌سازد. کلید فقط یک بار نشان داده می‌شود.
4. مدیر در `/admin` کلید را وارد می‌کند و فقط به پنل همان رستوران می‌رسد.

## قواعد
- هر کلید به یک رستوران تعلق دارد و نمی‌تواند به رستوران دیگری دسترسی دهد.
- باطل کردن لایسنس در `/super` همهٔ نشست‌های باز آن را فوراً می‌بندد.
- کلید در پایگاه داده به صورت هش ذخیره می‌شود؛ متن کامل کلید دوباره قابل خواندن نیست.
- ورود با نام کاربری و رمز عبور از صفحهٔ مدیریت حذف شده است.

## محدودیت‌ها
- پنل فروشنده و ورود با لایسنس فقط روی Worker (Cloudflare) کار می‌کنند.
- نسخهٔ GitHub Pages فقط منوی عمومی را نشان می‌دهد و API ندارد.
- نسخهٔ Python (`server.py`) ورود با لایسنس ندارد؛ برای کار محلی پنل مدیر با این نسخه باز نمی‌شود.

## نکتهٔ امنیتی
کلیدها و رمزهای عبور را در گفتگو، گیت یا فایل متنی قرار ندهید. اگر کلیدی لو رفت، همان لایسنس را باطل کنید و کلید تازه بسازید.
